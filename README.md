# [wilde.page](https://wilde.page)

My personal site: a short bio, publications and a feed.

- A small static site generator in Python, with no framework or web fonts
- Publications scraped from Google Scholar and Nesta
- Feed entries written as Markdown notes
- Light and dark themes
- Hosted on Cloudflare

`uv run hw.py serve` to preview, `uv run hw.py deploy` to publish.
